# Передача проекта

Прочитать README, docs/00, 02 и 12. Подтверждённые USB AP и V4/V5 QR не переделывать без запроса. Последний запрос функций: проверка видео/выбранные исправления FullHD1920×1080 с fps<=24 и HDMI→аналог. Пакет подготовлен, результата установки нет.

Фактическая база в доступном коде — /data/karaoke/db/karaoke.db; не подменять её ранней 20KiB копией /root/karaoke/karaoke.db. Полного eMMC образа нет. На устройстве одна USB Wi-Fi, builtin wlan0 используется как station. Новый kernel не совместим автоматически с сохранённым module.

Не импортировать app.py в облаке. Не менять zapret/bgutil/HDD/network ради UI. Сохранять пустой effective ExecStartPre. Не считать временные /tmp зависимости переносимым окружением. Начать с hashes фактического устройства, не повторять установку вслепую.

Неполные внешние imports, version status, source map, algorithms, tests, recovery и перенос перечислены в документации. Все сведения — срез доступных материалов 15.10.2026, не онлайн-наблюдение устройства.
