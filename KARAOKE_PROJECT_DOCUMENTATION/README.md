## Код и версии

- `sources/` — сохранённые рабочие каталоги и исследования без runtime caches.
- `versions/device-confirmed-v5/` — реконструированный набор известных подтверждённых файлов.
- `versions/prepared-media-audio-v1/` — следующий подготовленный набор.
- `evidence/` — исходные вложения, история и исходные сведения о проверках.
- `tools/verify_package.py` — проверка целостности пакета без импорта приложения.
- `tools/collect_device_snapshot.sh` — отдельно запускаемый сбор недостающих данных на HDD.
- `tools/extract_sources.py` — извлечение текстовых исходников из единого Markdown.

Запуск проверки из корня распаковки: `python3 tools/verify_package.py .`.

**Не запускайте все исторические install/rollback/test scripts подряд.** Они могут менять сеть и относятся к разным baseline. Документация сама не выполняет установку.
